# Directivas Multi-Agente (Antigravity, Codex y Claude Code)

Este repositorio educativo de **Campuslands** (`campuslands-bases-datos-vectoriales-qdrant-interactivo`) enseña **Bases de Datos Vectoriales**, **Embeddings de IA**, indexación **HNSW / Product Quantization**, la **Arquitectura de Qdrant** (`Collections`, `Distance Metrics`, `Points`, `Storage`, `Clients`) y un ejercicio práctico completo de búsqueda semántica con IA en Node.js (ESM).

## Reglas de Sincronización con Obsidian y Graphify
1. Antes de editar archivos, ejecutar `git status --short`.
2. Consultar contexto en Obsidian (`memoria contexto campuslands-bases-datos-vectoriales-qdrant-interactivo`) y el grafo en `graphify-out/graph.json`.
3. Al finalizar cambios:
   - Actualizar grafo: `graphify update .`
   - Exportar a Obsidian: `graphify export obsidian --dir "$HOME/Documents/OBSIDIAN/PROGRAMACION/Graphify/campuslands-bases-datos-vectoriales-qdrant-interactivo"`
   - Refrescar memoria: `memoria refresh`
4. Mantener el visor de código estilo **VS Code Dark+** en `index.html` con tokenizador léxico de pasada única y salto de línea automático (`white-space: pre-wrap; word-break: break-word;`) sin recortar ni ocultar líneas.
